# Mull-CNN

Code and figures for a research paper on kidney CT image classification using a multi-level CNN (Mull-CNN) architecture.

## Overview

This repository contains the implementation and supporting materials for a research paper evaluating Mull-CNN against baseline architectures (VGG-16, ResNet-50) for kidney CT classification.

## Contents

- `kidney_ct_classification_consolidated.ipynb` — main experiment notebook
- `figures/` — figures generated for the paper
